# Inversion-de-dependencias
El proyecto aplica el principio de inversión de dependencias al hacer que AdmProducto dependa de la abstracción EnvioRecibo, en lugar de depender directamente de clases concretas como EnviarEmail o EnviarApp.
Esta organización reduce el acoplamiento, facilita el mantenimiento y permite incorporar nuevos mecanismos de envío sin modificar la lógica principal del programa. Con las mejoras señaladas, el diseño puede resultar más seguro, flexible y fácil de ampliar.
